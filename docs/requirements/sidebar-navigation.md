### REQ-001: 좌측 사이드바 네비게이션 렌더링
- **설명**: 화면 좌측에 수직 사이드바를 고정 배치. 전체 화면 높이를 차지.
- **우선순위**: P1
- **수락 기준**:
  - [ ] Given 앱이 로드되면, When 화면을 보면, Then 좌측에 사이드바가 표시된다
  - [ ] Given 사이드바가 표시되면, Then 높이는 화면 전체를 차지한다

### REQ-002: 사이드바 접힘/펼침 토글
- **설명**: 사이드바 하단 또는 상단의 토글 버튼으로 접힘(아이콘만)/펼침(아이콘+텍스트) 전환
- **우선순위**: P1
- **수락 기준**:
  - [ ] Given 사이드바가 펼쳐져 있으면, When 토글 버튼 클릭, Then 아이콘 모드(~60px)로 전환
  - [ ] Given 사이드바가 접혀있으면, When 토글 버튼 클릭, Then 펼침 모드(~200px)로 전환
  - [ ] Given 전환 시, Then 부드러운 애니메이션 적용

### REQ-003: 메뉴 항목 표시 및 활성 상태
- **설명**: 각 메뉴 항목에 아이콘 + 라벨 표시. 현재 선택된 항목 하이라이트.
- **우선순위**: P1
- **수락 기준**:
  - [ ] Given 메뉴가 선택되면, Then 해당 항목에 좌측 보더 + 배경 하이라이트
  - [ ] Given 사이드바가 접혀있으면, Then 아이콘만 표시되고 활성 표시 유지

### REQ-004: "포트폴리오 시뮬레이터" 메뉴 항목
- **설명**: 기존 포트폴리오 시뮬레이터 전체 기능을 하나의 메뉴 항목으로 배치
- **우선순위**: P1
- **수락 기준**:
  - [ ] Given "포트폴리오 시뮬레이터" 메뉴 선택, Then 기존 3-column 레이아웃이 메인 영역에 표시
  - [ ] Given 기본 로드 시, Then "포트폴리오 시뮬레이터"가 기본 선택 상태

### REQ-005: 확장 가능한 메뉴 구조
- **설명**: 메뉴 항목을 배열/config로 관리하여 새 기능 추가가 용이한 구조
- **우선순위**: P1
- **수락 기준**:
  - [ ] Given 새 기능을 추가하려면, When menuItems 배열에 항목 추가, Then 사이드바에 자동 표시
  - [ ] Given 메뉴 config, Then id, label, icon, component 필드 포함

### REQ-006: 메뉴 클릭 시 콘텐츠 영역 전환
- **설명**: 사이드바 메뉴 클릭 시 메인 콘텐츠 영역이 해당 뷰로 전환
- **우선순위**: P1
- **수락 기준**:
  - [ ] Given 메뉴 A 선택 상태에서, When 메뉴 B 클릭, Then 메인 영역이 B 뷰로 전환
  - [ ] Given 라우터 없이, Then 상태 기반 렌더링으로 구현

### REQ-007: 반응형 사이드바 (모바일)
- **설명**: 모바일(md 이하)에서 사이드바를 햄버거 메뉴로 전환
- **우선순위**: P2
- **수락 기준**:
  - [ ] Given 화면 너비 < 768px, Then 사이드바 숨김 + 상단 햄버거 버튼 표시
  - [ ] Given 햄버거 클릭, Then 사이드바 오버레이로 표시

### REQ-008: 하단 상태바 표시
- **설명**: 사이드바 하단에 시스템 상태 정보 표시
- **우선순위**: P2
- **수락 기준**:
  - [ ] Given 사이드바 펼침 모드, Then 버전, 상태, 날짜 표시
  - [ ] Given 사이드바 접힘 모드, Then 상태 도트만 표시

### REQ-009: 금융 대시보드 다크 테마 유지
- **설명**: 사이드바가 기존 터미널/금융 대시보드 다크 테마와 일관성 유지
- **우선순위**: P1
- **수락 기준**:
  - [ ] Given 사이드바 UI, Then bg-[#0d1117] 배경, 모노스페이스 폰트, 슬레이트 컬러 사용
