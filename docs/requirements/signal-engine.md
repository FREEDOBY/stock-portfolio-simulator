## 2. 시그널별 상세 로직

### 시그널1: 항상 매수 (+1, 가중치 0.5)

### 시그널2: OECD CLI MoM%
- 매수: MoM% 3개월 연속 음수이며 절대값 줄어듦
- 매도: MoM% 3개월 연속 양수이며 절대값 줄어듦

### 시그널3: 키친사이클
- PMI 상승 + 재고 감소 → Phase1 (+2)
- PMI 상승 + 재고 증가 → Phase2 (+1)
- PMI 하락 + 재고 증가 → Phase3 (-1)
- PMI 하락 + 재고 감소 → Phase4 (0)

### 시그널4-매수: 200주선 접근
- 거리 > 30% → 0 (중립)
- 10~30% → +0.5 (관심)
- 0~10% → +1 (매수 준비)
- < 0% → +2 (적극 매수)

### 시그널4-매도: MACD 3쌍봉
- 주가 고점 상승 + MACD 고점 하락 3개 → -2 (매도)
- 2개 → -1 (주의)

### 시그널5: MACD 쌍바닥 + RSI
- 주가 저점 하락 + MACD 저점 상승 → +2 (매수)
- RSI <= 25 → +1.5 (극과매도)
- RSI <= 30 → +0.5 (과매도)

### 시그널6: 계단식법 (Phase3,4 전용)
- Drawdown <= -15% → +0.5 (준비)
- Drawdown <= -20% → +1 (1단계)
- Drawdown <= -30% → +1.5 (2단계)
- Drawdown <= -40% → +2 (3단계)

### 종합 점수
가중합 / 가중치합, 범위 -1 ~ +1
- >= +0.6 → 적극 매수
- +0.2 ~ +0.6 → 매수
- -0.2 ~ +0.2 → 관망
- -0.6 ~ -0.2 → 주의
- <= -0.6 → 매도
