### REQ-001: FRED API 클라이언트
- **설명**: FRED REST API를 호출하여 경제 지표 시계열 데이터를 수집
- **수락 기준**:
  - [ ] Given FRED API 키가 설정되면, When 시리즈 ID와 기간 지정, Then JSON 시계열 반환
  - [ ] Given 유효하지 않은 시리즈 ID, Then ValueError 발생

### REQ-003: Yahoo Finance 매크로 데이터
- **수락 기준**:
  - [ ] Given ^IXIC 주봉 요청, Then 1300주+ 데이터 반환 (200주선 계산용)
  - [ ] Given ^VIX 일봉 요청, Then 2년 데이터 반환

### REQ-005: 데이터 캐싱
- **수락 기준**:
  - [ ] Given 첫 호출 성공, When 두 번째 호출 실패, Then 첫 번째 데이터 반환
  - [ ] Given 캐시 사용 시, Then is_cached=True 플래그 포함
